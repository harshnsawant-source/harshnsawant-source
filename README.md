### Hi, I'm Harsh: AI engineer and safety researcher

I find where language models make things up, and build systems that refuse to.

**Projects**

- **[Engram](https://github.com/harshnsawant-source/engram)**: a memory engine for AI assistants. Memories consolidate while it "sleeps", unused ones fade, and every answer cites the memory it came from or refuses. Refused 20/20 unanswerable questions with 0 made up. [Live demo](https://engram-blue.vercel.app)
- **[still-holds](https://github.com/harshnsawant-source/still-holds)**: do well-known alignment findings still hold on the open models you can actually run? Pre-registered replications on free hardware, enforced from git history; 2,880 trials, every number recomputable without a GPU. Found a bias that damaged answers while the standard accuracy metric reported improvement.
- **[OIL](https://github.com/harshnsawant-source/OIL)**: private, local-first Q&A over confidential documents. Answers cite the exact file and page, or return NOT_FOUND. 14/14 on a labelled citation and refusal test.
- **[evalnoise](https://github.com/harshnsawant-source/evalnoise)**: tells you whether one model really beat another, or the gap is just noise. Paired tests against an A/A noise floor; 60 tests, CI.
- **[Detect or Degrade](https://github.com/harshnsawant-source/swarm-detect-or-degrade)**: Apart Research × AIAF Swarm Alignment Hackathon. Can colluding AI agents drain a fleet's shared safety checks? A simulation of 7 oversight strategies.
- **[Self-improving code reviewer](https://github.com/harshnsawant-source/self-improving-code-reviewer)**: learns from which findings I keep, and is built so it can't raise its score by staying quiet.
- **[Obsidian Intelligence Layer](https://github.com/harshnsawant-source/Obsidian-intelligence-layer)**: the early public version of my multi-agent assistant. The current system, AVIORA, is private.
